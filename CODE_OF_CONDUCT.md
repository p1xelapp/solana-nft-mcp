# Code of conduct

This project is small and the rules are short.

## What is expected

Be straight with people. Say what you observed, what you inferred, and which is which. Disagree
with the argument rather than the person. Assume the other reader is busy and competent.

If you report a problem, say what you did, what you expected and what happened, with the version
you were on. If you fix one, say what you verified and how.

## What is not accepted

Harassment, personal attacks, and unwelcome attention. Insults about who somebody is rather than
what they wrote. Publishing anyone's private information. Deliberately wasting a maintainer's
time.

This applies in issues, pull requests, commit messages and anywhere else the project is
discussed.

## Reporting

Open a private security advisory on this repository, or contact me through the address on
the profile that owns it. Reports come to me and nobody else.

A report gets an answer. Depending on what happened, the response ranges from a request to edit
a comment, through a warning, to a block from the repository. Repeated or severe behaviour skips
straight to the block.

## Scope

This covers project spaces and any place where somebody is representing the project.
